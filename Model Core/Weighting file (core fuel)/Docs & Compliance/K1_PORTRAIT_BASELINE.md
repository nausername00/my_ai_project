# K1 立绘设定与基准规范（输入地基）

> 状态：本文件是 K1「头像 → 立绘补全」的**输入规范**，只定义设定表、基准规则与验收口径，
> 不实现图片生成。图像生成引擎路线尚未拍板（见文末「引擎路线」），生成环节待选定后接入。

## 1. 特征设定表（角色资料卡扩展）

接收头像 / 参考图后，用现有视觉理解能力**整理出结构化设定**，而不是直接宣称"认出身份"。
模型推测的每一项都标注为「待用户确认」，用户可填或选择当前已拥有的选项。

| 字段 | 说明 | 示例（可选项） |
|---|---|---|
| 脸型 | 参考头像轮廓 | 瓜子脸 / 圆脸 / 方脸 / 鹅蛋脸 / 待确认 |
| 发型 | 长度、刘海、发色 | 长直发 / 双马尾 / 短发 / 卷发 |
| 饰品 | 发饰、耳饰、服饰细节 | 蝴蝶结 / 发卡 / 项链 / 无 |
| 识别点 | 一眼记住的独特征 | 泪痣 / 呆毛 / 异色瞳 / 伤疤 |
| 气质 | 整体观感（主观，需人审） | 清冷 / 元气 / 温柔 / 神秘 |
| 配色 | 主色、辅色、强调色 | 白 + 蓝 + 金 |
| 画风 | 风格参考 | 日系赛璐璐 / 厚涂 / 扁平 / 水彩 |
| 比例 | 全身 / 半身 / 头身比 | 二头身 / 六头身 / 半身立绘 |

输出物：一份「特征表 + 识别点 + 气质」文本设定，用户逐项确认后可保存为角色资料。

## 2. 基准立绘规则

- **统一画布与落点**：同一角色所有姿势使用同一画布尺寸（推荐竖版 1024×1536，可调）；
  人物底部对齐、头顶预留空间，多图切换不忽大忽小。
- **中性基准图**：确认后保存为基准图，后续编辑一律「只改指定动作」。
- **保持不变项**：服装、五官、画风在基准图确认后保持一致；脸型 / 发型 / 饰品除非用户
  明确要求，否则不改变。
- **输出要求**：透明背景（PNG）；新增 / 编辑时原图不被覆盖，基准图可回读。
- **二次编辑**：思考、摊手等姿势变化时，明确"只改动作"。

## 3. 动作清单（分层，供后续 K3/K4 绑定与编排）

| 动作 | 涉及部件 | 时长参考 | 说明 |
|---|---|---|---|
| 眨眼 | 眼 | 0.15–0.3s | 幅度小，回中性 |
| 小幅说话 | 眼、嘴、主体 | 随语音 | 开口跟随音量，停顿闭嘴 |
| 连续转头 | 头、颈 | 0.5–1s | 动作跟语义走 |
| 抬手 | 手臂、手 | 0.6–1.2s | 重点指向用 |
| 思考 / 摊手姿势 | 全身 | 静止保持 | 可整体姿势切换 |

每个动作必须：有触发语义、有明确时长、结束时回到中性。

## 4. 引擎路线（待拍板）

| 路线 | 说明 | 依赖 / 影响 |
|---|---|---|
| A · 本地 ComfyUI / SD | 便携版安装 + 模型约 6–15GB，吃显存；生成留本机 | 无需联网、无额外账号，最符合本地默认可信 |
| B · 云端图像 API | 接入外部生成服务，需密钥或授权；图片出本地 | 逐次授权、明示数据去向与提供方 |
| C · 盘点先行 | 先交付特征表 / 设定（第 1 节），生成环节后接 | 当前即可用，不引入依赖 |

**建议**：先走 C（设定盘点，可立即落地），同时评估 A 的设备与配额；B 仅在用户明确愿意授权时启用。

## 5. 验收口径

- 特征表由用户逐项确认；生成 / 编辑结果由用户预览确认。
- 二次编辑仅改指定动作；画布尺寸与人物落点可机器比对。
- 透明背景输出；原图不被覆盖，基准图可回读。
- 仅视觉描述能力时，不得把"特征描述"包装成"图片生成"。
