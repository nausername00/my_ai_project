# 墨灵使用政策（USAGE_POLICY）

本文件描述墨灵（Moling）的设计边界与使用约定，帮助用户理解哪些行为
是内置支持的、哪些需要显式授权、哪些被明确禁止。

## 本地优先

- 默认推理走**本地** Ollama 服务（`http://127.0.0.1:11434`）；服务不可达时
  返回错误而非伪造输出，也不会静默切换到云端。
- 云端 OpenAI 兼容后端（`MODEL_BACKEND=cloud`）**默认关闭**；必须同时显式
  设置 `CLOUD_API_BASE_URL`、`CLOUD_API_KEY`、`CLOUD_API_MODEL` 才会启用。
  启用后提示词与会话文本会发送到所配置的端点。

## 数据与隐私

- 会话消息**不落盘**；窗口关闭、新对话、切换角色卡即丢弃（仅内存保留最近 20 条）。
- 记忆为**显式写入**（`POST /v1/memory`），可逐条编辑/删除/导出/导入；
  标记 `private` 的记忆不会进入提示词，也可全局关闭记忆注入。
- 记忆文件为本地明文 JSON，无云同步；请勿存放机密信息。
- 参考语音样本仅存于 Electron 用户数据目录，不进入提示词或模型训练。

## 行为边界

- 角色卡决定人格表达；"模拟状态"是基于规则的风格仿真，不声称拥有情感或意识。
- Agent 规划层（`/v1/agent/plan`）**只规划不执行**；工具执行必须经由
  Electron 主进程的一次性授权。
- 项目文件工具仅支持：列出文件、读取合规 UTF-8 文本（≤256 KB）、
  以独占创建方式新建文本文件（≤4000 字符）。**不支持**覆盖、删除、网络、联系人操作。
- 视觉输入仅限 loopback 视觉模型，无自动屏幕监控。

## 禁止用途

- 未经授权克隆真人声纹、伪造身份或冒充他人。
- 将远程 `OLLAMA_URL` / 云端端点用于发送明文敏感数据而未作相应保护。
- 将本脚手架用于需要医疗、法律、金融等专业资质的正式决策（本项目不提供此类结论）。
