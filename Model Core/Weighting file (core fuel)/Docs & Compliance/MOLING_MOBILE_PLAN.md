# 墨灵手机陪伴原型（远期 · 设计草案）

> 状态：**远期，不设时间表**。本文只登记方向与最小原型边界，不承诺实现；任何一版动手前先回到这里对齐"主权边界"。

## 目标

电脑关闭后，墨灵能在手机上继续陪伴：**同一个伙伴、同一份记忆、按需唤醒**。

## 已有基础（S 系列可直接复用）

- **S1 分身底座**：分身状态机 / 睡眠唤醒 / 唤醒确认 / 阈值询问——手机端可沿用同一套"睡眠不占推理、唤醒需确认"。
- **S3 记忆主权**：长期记忆只由主墨灵统一写入，分身成果经回写接口提交、可撤销——手机端不另开记忆通道。
- **S4 自省回路**：introspection / suggestions / daily-brief——手机端可消费"每日简报"做轻量提醒。

## 最小原型（第一个可验收版本）

1. **会话断点续接**：会话状态（当前分身、上下文摘要、未完成目标）导出为可恢复快照；手机端从快照继续，不重述、不丢失。
2. **摘要续聊**：手机端以"会话摘要 + 用户新消息"起步，明确标注"承接自电脑端"。
3. **轻量提醒通道**：可选启用"每日自省简报"推送；默认关闭，用户开启后才工作（对齐 J5 的边界）。

## 明确不做（保持克制）

- 不建第二套长期记忆存储（主权唯一）。
- 不做实时多端同步（先做断点，不做镜像）。
- 不默认后台联网（对齐"默认不外部调用"边界）。

## 验收标准（将来启用时）

- 电脑端会话可导出快照；手机端可恢复且上下文一致。
- 手机端唤醒仍需用户确认；简报推送默认关闭。
- 全部分身能力与授权边界与桌面端一致。
