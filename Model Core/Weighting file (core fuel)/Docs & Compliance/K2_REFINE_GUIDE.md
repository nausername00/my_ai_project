## 只需两件小事（可选，5 分钟）

**① 修眼睛（推荐做，简单）**
- 在图层面板点 `04_eye` 前的小眼睛图标先隐藏它，看参考层里两只红眼的位置
- 点选 `04_eye` 图层 → 用「套索工具」(L) 沿参考层右眼轮廓圈出 → 「图层→复制图层」→ 「编辑→变换→水平翻转」→ 用「移动工具」(V) 拖到左眼位置对齐参考
- 完成后取消隐藏，双眼应能对上参考层

**② 修嘴（可选）**
- 点选 `03_mouth` → 用「套索工具」把不属于嘴的像素删掉（Delete 键），只留口线+唇
- 若嫌麻烦：**直接跳过**，K3 阶段我会用「整图变体切换」做表情，不依赖精确嘴层
