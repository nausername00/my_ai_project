# K1 立绘生成经验（墨灵「试画」知识库）

> 写给墨灵自己看的手册。**你如果哪天想自己画一张立绘，先读这份，再调 `draw_portrait`。**
> 这些经验来自 2026-10-12 前后 11 轮真实生成的踩坑与修正，全部经过验证。

## 0. 一句话结论

- 你的基准形象已定稿：**红眸 · 白猫耳（粉内耳）· 银白长发 · 黑白主色带蓝红点缀的清冷少女**。
- 生成立绘 = 用本地 ComfyUI + Counterfeit-V2.5 底模，**竖版 1024×1536、20 步、cfg 7.0**。
- 生成本身不难；难的是**下半身不崩**和**背景不脏**——这两点靠负面词和"多 seed 挑图"解决。

## 1. 定稿特征表（2026-10-12）

| 部位 | 定稿值 | 备注 |
|---|---|---|
| 眼睛 | 鲜红眼眸（bright red eyes） | 备选：星空蓝紫 / 翠绿宝石（v2 已验证可生成） |
| 耳朵 | 白色猫耳（粉内耳） | 不要黑色兽耳、不要普通猫娘 |
| 头发 | 银白超长发，无马尾 | 严禁双马尾 / 单马尾 / 辫子 |
| 服装 | 黑白主色 + 蓝红点缀 + 金饰 | 军装式外套或高领外套 + 裙；不要女仆装、不要全白纱裙、不要紫披风 |
| 气质 | 清冷、沉静、微微神秘 | 不要过度微笑、不要妩媚 |
| 姿势 | 正面、双腿站立、双手自然/交叠 | 中性姿势，便于后续动作绑定 |
| 背景 | 生成期用纯白 | 透明化用 rembg；背景装饰越少，透明越干净 |

## 2. 提示词模板（已封装在 `Source code engine/portrait_prompts.py`）

- `build_positive(style_prompt=...)`：基准正向词 + 可选追加风格。
- `NEGATIVE_TEMPLATE`：**不要删里面的腿部防护**，是 11 轮踩坑的结晶。

### 负面词为什么这么长（每条都是真实事故）

| 负面词 | 曾发生的事故 |
|---|---|
| `triple legs / extra legs / fused legs` | 三条腿、腿变手、腿分离（下半身崩坏三连） |
| `skirt overlap / clipping` | 裙子重叠穿模 |
| `maid outfit / apron / frilly skirt` | 女仆装（用户否决） |
| `twin tails / pigtails` | 双马尾（用户明确不要） |
| `garbage bag / plastic bag / holding bag` | 手里拎垃圾袋/白色箱状物 |
| `two girls / multiple people / duo` | 画成两个人 |
| `gun / weapon / rifle / sword` | 出现枪械武器 |
| `mermaid / fish tail` | 人鱼尾 |
| `cape / hood / scarf / ribbon trail` | 披风/兜帽/飘带——它们会留在透明边缘，污染立绘 |
| `flower petals / mist / fog / smoke` | 花瓣雾/烟雾背景残留 |

### 正向词的关键技巧

- 服装必须**具体**（"black high collar jacket + skirt"），抽象词（"优雅服装"）会漂成白袍/白纱裙。
- 眼睛颜色加权重 `(bright red eyes:1.3)`，否则模型经常忽略。
- 想要星空/翠绿眼：只把眼睛词换掉，其他不动（`build_positive(override={"eyes": ...})`）。

## 3. 生成流程（draw_portrait 已实现）

```
墨灵调用 draw_portrait
  → 默认按定稿特征生成 1-3 张草稿
  → 保存到 Character/K1 Portrait/drafts/moling_draft_<seed>.png
  → 返回路径列表
```

- `style_prompt`：追加风格方向（例如"给我加一件蓝色披风试试""换成星空眼睛"）。
- `count`：1-3 张，**建议 3 张**——多 seed 挑图是成功率最高的手段。
- `seed_base`：想复现某张就填它的 seed；0 = 自动用推荐种子列表。
- ComfyUI 没启动时工具会返回 error + 提示，不会中断对话。

### 挑图标准（我每次帮你挑也是按这个）

1. **先看腿**：三条腿 / 腿变手 / 裙重叠 / 腿分离 → 直接淘汰。
2. **再看多余物件**：垃圾袋、箱、武器、双人、人鱼尾 → 淘汰。
3. **再看发型**：双马尾 → 淘汰（除非你想试新造型）。
4. **看服装**：白袍 / 白纱裙 / 女仆感 / 紫披风 → 淘汰。
5. 剩下来的里选**气质最像"清冷沉静"**的那张。

### 透明化（rembg）

- 优先 `u2net` 模型（比默认 bria-rmbg 残留碎片少）。
- **背景装饰越少越好**：披风/兜帽/飘带/烟雾会让 rembg 分不清哪些属于人物 → 透明边缘脏。
- 如果透明后仍有边缘杂质：回到生成侧把对应负面词加强，**别硬修透明图**。

## 4. 踩坑记录（不想再犯的错）

1. **女仆装事故**：v1 用了"gothic lace"类词 → 裙摆蕾丝+丝带缠绕，被否。之后服装词全部军装化/制服化。
2. **下半身崩坏**：1024×1536 竖版 + 20 步标准采样，腿部仍偶尔崩；负面词 + 多 seed 才压住。**生成前先问自己：负面词带全了吗？**
3. **背景红色装饰**：prompt 里出现 "red accents" 时模型会在背景也画红色线条/红瞳物体 → 背景词明确 `plain pure white background`，并禁 `cape/hood/ribbon trail`。
4. **复现同一张**：seed + 提示词完全一致才能复现；改任何一个字都会换图。
5. **透明化不是修复工具**：生成有杂质 → 改 prompt 重新生成，不要在透明图上涂改。

## 5. 还能怎么变（已验过可行）

| 想变 | 做法 |
|---|---|
| 星空蓝紫眼 | 眼睛词换 `starry blue-violet eyes:1.3`（v2 star 版验证） |
| 翠绿宝石眼 | 眼睛词换 `emerald green eyes:1.3` + `green gem earrings`（v2 emerald 版验证） |
| 更华丽（参考图灵感） | 追加 `elegant majestic gothic style, graceful noble atmosphere` + 具体裙装词（图1 权杖礼服/图2 铠甲裙的启发；注意服装必须写具体） |
| 特定风格 | `style_prompt` 写具体名词（军装/礼服/和风），避免抽象形容词 |

## 6. 边界

- 只连本地 ComfyUI（127.0.0.1），绝不允许远程地址。
- 草稿只写 `Character/K1 Portrait/drafts/`，**绝不覆盖定稿** `baseline_v5_0_raw.png`。
- 提示词由特征表组装；生成是本地计算，不向外部发送任何数据。
